# Learning

Visual learning handbooks: mental models, principles and frameworks, built as interactive HTML.

| Handbook | What it is | Open |
|---|---|---|
| Super Thinking, mapped | 59 mental models from *Super Thinking* (Weinberg & McCann) as a mind map, with a visual action plan and real-world examples for each model | [`super-thinking/index.html`](super-thinking/index.html) |
| Software Laws, mapped | All 57 software engineering laws as a seven-floor building: code (DRY, KISS, YAGNI, SOLID…), quality (Murphy, Technical Debt, Testing Pyramid…), scale (Amdahl, Little, Metcalfe… with live calculators), architecture (Gall, CAP, Hyrum…), time (Hofstadter, Parkinson, Goodhart…), people (Conway, Brooks, Bus Factor…) and decisions (Occam, Sunk Cost, Lindy, Chesterton’s Fence…). Each law has a diagram, steps, before/after, real-world examples and links to book 1. Includes a 62-situation quiz, tension pairs and a printable cheat sheet. | [`software-laws/index.html`](software-laws/index.html) |
| The AI Handbook | A nine-floor visual field guide to AI engineering, 60 chapters from how models learn to shipping agents: LLM internals (tokens, attention, temperature, reasoning, hallucination), building with models (structured output, tool calling, prompt and context engineering), grounding and RAG, agents and the harness, MCP, skills, multi-agent and coding agents, evals and observability, security and guardrails (prompt injection, the lethal trifecta, OWASP LLM Top 10 2026, EU AI Act), and running in production (inference, serving, cost, LLMOps, system design). Each chapter has a big idea, a diagram, an interactive toy, myth vs reality and a delivery lens; each floor ends with a cheat card and quiz. | [`ai-handbook/index.html`](ai-handbook/index.html) |
| The SAA-C03 Handbook | A ten-floor visual study guide for the AWS Certified Solutions Architect – Associate (SAA-C03) exam, 59 chapters organised by service area: foundations, identity and governance, networking, compute, storage, databases, decoupling and data, security, resilience and DR, and cost and exam strategy. Every chapter is tagged to its official exam task, with diagrams, calculators (subnets, DynamoDB capacity, IAM policy evaluation, DR targets, S3 lifecycle, data transfer), an exam lens of question keywords and floor quizzes. Includes a timed, domain-weighted 65-question mock exam with explanations. | [`saa-c03-handbook/index.html`](saa-c03-handbook/index.html) |
| The Inference Engineering Handbook | A nine-floor visual guide to serving LLMs fast and cheaply, 48 chapters built around Stanford CS336's inference lecture: prefill vs decode and the metrics that matter, GPUs and the roofline, the KV cache (GQA, MLA, long context), quantisation, MoE and distillation, speculative decoding and kernels, the serving engine (continuous batching, PagedAttention, prefix caching, chunked prefill), distributed inference (tensor, pipeline and expert parallelism, disaggregated prefill/decode, KV-aware routing), production (goodput, capacity planning, observability, overload) and economics (cost per million tokens, API vs self-hosted, hardware choice). Each chapter has a big idea, a diagram, a calculator or simulator, myth vs reality and an engineer's lens; each floor ends with a cheat card and quiz. | [`inference-handbook/index.html`](inference-handbook/index.html) |
| The System Design Handbook | A nine-floor visual guide to designing systems that stay fast, correct and affordable as they grow, 54 chapters: a repeatable design method with estimation and latency numbers, the edge and APIs (DNS, CDNs, load balancers, rate limiting), storing and scaling data (indexes, transactions, caching, replication, sharding, consistent hashing, CAP), async and events (queues, Kafka, idempotency, streams, outbox and sagas), distributed systems realities (retries, clocks, Raft, IDs, locks), reliability and operations (SLOs, failover, resilience patterns, observability, safe deploys, security), and twelve worked case studies from URL shortener to payments, RAG and agent platforms. Each chapter has a diagram or step-through, a calculator or simulation and an architect's lens; each floor ends with a cheat card and quiz. Includes a timed 45-minute design drill with 18 prompts and a self-scoring rubric. | [`system-design-handbook/index.html`](system-design-handbook/index.html) |

Open any `index.html` in a browser. Each page is self-contained (fonts load from Google Fonts).
