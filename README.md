# Learning

Visual learning handbooks: mental models, principles and frameworks, built as interactive HTML.

| Handbook | What it is | Open |
|---|---|---|
| Super Thinking, mapped | 59 mental models from *Super Thinking* (Weinberg & McCann) as a mind map, with a visual action plan and real-world examples for each model | [`super-thinking/index.html`](super-thinking/index.html) |
| Software Laws, mapped | 57 software engineering laws as a building, one floor per part. Open floors: Ground (Part VI, coding principles: DRY, KISS, YAGNI, SOLID, Law of Demeter, Boy Scout Rule) and Floor 1 (Part IV, quality: Murphy, Postel, Broken Windows, Technical Debt, Linus, Kernighan, Pesticide Paradox, Testing Pyramid, Lehman, Sturgeon). Floor 2 (Part V, scale: Amdahl, Gustafson, Little, Metcalfe) has live calculators. Floor 3 (Part I, architecture: Gall, Leaky Abstractions, Tesler, CAP, Hyrum, Second-System Effect, Fallacies of Distributed Computing, Unintended Consequences). Includes a quiz, tension pairs and a printable cheat sheet. Floors 4–6 (time, people, decisions) coming. | [`software-laws/index.html`](software-laws/index.html) |

Open any `index.html` in a browser. Each page is self-contained (fonts load from Google Fonts).
